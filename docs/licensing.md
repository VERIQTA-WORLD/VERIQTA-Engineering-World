# Licensing decision pending

No licence existed in the starting repository. No content or code licence has been selected on the owner's behalf. Public visibility alone does not supply an open-source or open-content licence. Third-party asset notices retain their own terms.

## Choices for the owner

A common approach is CC BY 4.0 for original educational prose and MIT or Apache-2.0 for original code. CC BY-SA 4.0 adds a share-alike requirement for content adaptations. These are candidate choices, not terms applied to this repository. The owner should select scope, confirm rights in contributions and branding, and add the actual licence text before inviting reuse under those terms.

Until that decision is recorded, do not describe this repository as licensed under MIT, Creative Commons or any other licence. Contributors should submit only work they are entitled to share and understand that general reuse terms remain unresolved. This page records repository status; it does not offer legal advice.
