# Solution: An average can hide an outage

`VW-C004` · Solution and reasoning

## Explained answer

(990 × 40 + 10 × 8000) / 1000 = 119.6 ms. Only 990/1000, or 99%, meet 300 ms. A healthy-looking mean hides ten badly served requests. Use histogram bucket counts or event records with defined eligibility rather than averaging local percentiles.

A zero denominator is unknown/no traffic, not 100% good. Add missing-telemetry detection and an external signal. A latency SLI that excludes failed requests must be paired with availability so fast errors cannot look healthy. Set an objective and window based on user needs rather than copying an arbitrary percentage.
