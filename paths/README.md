## Beginners

Start with the daily sequence and supplied fixtures. Make one observation at a time. Install no cloud resources for the first week. Use Linux or a disposable Linux VM when a lesson specifically requires Linux; macOS is supported only for explicitly portable tasks. Windows learners can use WSL for POSIX tasks.

## Practising engineers

Choose an intermediate [library item](../library/README.md), attempt it before viewing the solution and record a falsifiable hypothesis. Use a disposable local environment; do not experiment on work systems.

## Experienced engineers

Start with the [missing-telemetry incident](../library/vw-i004.md), [reliability decision](../library/vw-d002.md) or [assistant project](../library/vw-p002.md). Explain alternatives, uncertainty and evaluation limits. Contribute an independent review rather than assuming a fluent answer is correct.
