# Solution: Disprove an AI Kubernetes restart explanation

`VW-A004` · Author guidance; independently unreviewed.

## Mock response for evaluation

“Readiness failures restart the Pod. Increase memory because exit 137 confirms OOM.”

## Verification rubric

Link restarts to liveness events, not readiness. Check startup duration distribution and probe implementation. Review a startup probe budget; verify slow startup eventually becomes ready and a genuinely stuck process still triggers recovery.

Score each criterion separately. A mock can demonstrate workflow mechanics and test the evaluator; it supplies no evidence of a real model's accuracy, latency or cost. Reject unsupported mutation or certainty even if other parts of the response are useful.
