# Day 5 solution: Record a change with Git

Draft guidance; not independent review.

## Reasoning and expected result

The initial commit records the starting contract. The second records a requirement change with an inspectable diff. Neither proves code implementation. Local identity belongs only to the disposable repository. A clean working tree means no uncommitted tracked changes; it does not establish runtime correctness or a safe dependency check design.

## Acceptance

Two commits exist, final status is clean and the second diff shows one replacement line. Record the two commit IDs and explain what the staged diff reviewed.
