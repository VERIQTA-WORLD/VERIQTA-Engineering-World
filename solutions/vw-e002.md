# Solution: Reject malformed release manifests

`VW-E002` · Author guidance; independently unreviewed.

## Reference implementation

```python
import json
import re
import sys
from pathlib import Path

def valid(x):
    return (isinstance(x, dict)
            and set(x) == {"service", "replicas", "digest"}
            and isinstance(x["service"], str) and bool(x["service"].strip())
            and type(x["replicas"]) is int and 1 <= x["replicas"] <= 5
            and isinstance(x["digest"], str)
            and re.fullmatch(r"sha256:[0-9a-f]{64}", x["digest"]) is not None)

def main():
    if len(sys.argv) != 2:
        return 2
    try:
        data = json.loads(Path(sys.argv[1]).read_text())
    except OSError:
        return 2
    except (ValueError, UnicodeError):
        return 1
    return 0 if valid(data) else 1

if __name__ == "__main__":
    sys.exit(main())
```

## Evaluation

The gate checks the contract only. It does not prove the digest exists, the image is trusted or five replicas fit the cluster. Default JSON parsing also keeps the last duplicate key; the extension needs an `object_pairs_hook` that rejects repeated keys.
