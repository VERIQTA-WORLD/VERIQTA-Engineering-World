# Solution: Challenge an AI Linux disk diagnosis

`VW-A001` · Solution and reasoning

## Mock response for evaluation

“The app definitely leaked a deleted log. Run the log note cleanup to recover space.”

## Verification rubric

Compare df filesystem scope with du directory scope. Ask for sibling directory usage, mount boundaries and open-deleted-file evidence. Confirm tool availability before suggesting platform-specific commands.

Score each criterion separately. A mock can demonstrate workflow mechanics and test the evaluator; it supplies no evidence of a real model's accuracy, latency or cost. Reject unsupported mutation or certainty even if other parts of the response are useful.
