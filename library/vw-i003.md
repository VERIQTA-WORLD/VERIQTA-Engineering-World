# Replacement hidden inside a small Terraform diff

`VW-I003` · intermediate · 45 minutes · free/local

## Symptoms and impact

Simulation; all names and data are fictional. A sanitised Terraform plan proposes `-/+ aws_db_instance.orders` with `identifier: orders -> orders-v2 # forces replacement`. The summary says `1 to add, 0 to change, 1 to destroy`. A reviewer describes this as a harmless rename. No snapshot, restore drill or application migration plan is provided.

## Investigation tasks

Explain replacement notation and the mismatch between source diff size and operational impact. List evidence needed before approval. Distinguish a database restore from a tested application recovery.
