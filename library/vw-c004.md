# An average can hide an outage

`VW-C004` · intermediate · 30 minutes · free/local

## Question

Simulation: 990 requests take 40 ms and 10 take 8 seconds. The mean is 119.6 ms and an alert on mean latency above 200 ms never fires. Did all users receive acceptable service?

## Task

Verify the arithmetic. Define a request-based latency SLI using a 300 ms threshold. Explain why averaging instance percentiles is not a fleet percentile, and how missing traffic can disappear from a ratio.

## Verification

State good requests, total requests, resulting fraction and an explicit no-traffic policy. Separate availability from latency.

## Reflection

What would you measure if failures were never recorded by the application?
