# Solution: Find the large file without filling a disk

`VW-E001` · Author guidance; independently unreviewed.

## Worked approach

`wc -c "$lab/debug.log"` should report 13000. Independently use `python3 -c 'import os; from pathlib import Path; assert (Path(os.environ["lab"])/"debug.log").stat().st_size == 13000'`.

`du` rounding depends on the filesystem; do not hard-code its output. An open file descriptor can keep blocks allocated after unlinking. Establish process ownership and retention before rotating real logs. For cleanup use `rm "$lab/app.log" "$lab/debug.log" "$lab/keep.txt"` followed by `rmdir "$lab"`. A refusal to remove a nonempty directory is a useful scope guard.
