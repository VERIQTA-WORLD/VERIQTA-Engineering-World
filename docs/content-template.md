# Content submission template

Copy the relevant structure into one substantive learner page. Do not publish this template as an exercise. Create a separate solution and a JSON record using an existing record as the schema example.

## Practical item outline

Mission · Outcomes · Environment and scope · Prerequisite checks · Setup · Concepts · Tasks · Expected observations · Verification · Troubleshooting · Cleanup · Reflection · Sources · Solution link.

## Incident outline

Symptoms and impact · Available evidence (simulation or primary source) · Investigation tasks · Progressive hints · Verification · Reflection · Separate solution with evidence reasoning, alternatives, recovery and prevention.

## AI additions

AI task and boundaries · Sanitised input · Example interaction · Expected response characteristics · Failure modes · Independent verification · Final engineering decision.

## Metadata checklist

Assign the next unused stable ID. Specify topic/tags, type, difficulty, prerequisite IDs, estimated minutes, environment, cost, versions, source URLs/date, draft status, canonical path and solution path. Initialise execution as not-run with null environment/date/result. Never reuse an ID for a different learning outcome.
