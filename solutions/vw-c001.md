# Solution: A green deployment and a failed user request

`VW-C001` · Author guidance; independently unreviewed.

## Explained answer

The pipeline proves its configured checks passed for R42; it cannot prove checks it never performed. Running processes show liveness, not reachable or correct checkout behavior. The 503 evidence establishes a user-facing failure for the observed sample, not its cause.

A useful outcome is successful checkout requests / eligible checkout requests over five minutes, with explicit exclusion rules. Delivery and operations engineers should correlate request failures with release, route and dependency changes. Compare cohorts before expanding the rollout. A manual gate without better evidence merely moves responsibility.

## Evaluation

Reject answers that infer a failed database solely from a 503. A rollback decision needs safety evidence too: backward-compatible data changes, available prior artifacts and recovery monitoring.
