# Solution: An image tag is not a release identity

`VW-C003` · Author guidance; independently unreviewed.

## Explained answer

A tag can move while nodes retain different cached images. A digest identifies content; multi-platform indexes resolve to platform-specific manifests. Record both the index and selected platform manifest where relevant. Record source, build inputs, digest, platform and configuration revision; avoid publishing secret values.

Digest pinning prevents silent content changes at that reference. It does not prove provenance, eliminate vulnerabilities, ensure external dependencies are stable or prove the workload is correct. Use scan results and provenance with an update policy, then test promotion using the same artifact.
