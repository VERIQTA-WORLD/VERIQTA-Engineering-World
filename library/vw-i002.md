# A passing pipeline publishes a secret

`VW-I002` · intermediate · 45 minutes · free/local

## Symptoms and impact

Simulation; all names and data are fictional. A simulated CI log reads `+ curl -H Authorization:Bearer DEMO_NOT_A_REAL_TOKEN ...`. The script enabled `set -x` before constructing a header. The job succeeded; logs were visible to external contributors. The fixture token is fake. Real exposure scope is deliberately unspecified.

## Investigation tasks

Identify the exposure mechanism and propose containment in order. Separate log deletion from credential invalidation. Describe how to test the fix with a fake sentinel and inspect artifacts as well as logs.
