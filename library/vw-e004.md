# Render Helm values before approving a change

`VW-E004` · intermediate · 50 minutes · free/local

## Mission

A Helm values change silently disconnects a Service. Catch the mismatch before deployment.

## Outcomes

Compare rendered selectors and pod labels, and explain Kubernetes port routing.

## Environment and scope

Offline manifest review by default. Optional Helm 3 and a local disposable cluster; no cloud needed.

## Prerequisite checks

Understand Pods, Deployments and Services. Do not apply fixtures to a shared cluster.

## Setup

Simulation of rendered output:

```yaml
apiVersion: v1
kind: Service
metadata:
  name: orders
spec:
  selector: {app: orders, track: stable}
  ports:
    - port: 80
      targetPort: 8080
---
apiVersion: apps/v1
kind: Deployment
metadata:
  name: orders
spec:
  selector:
    matchLabels: {app: orders}
  template:
    metadata:
      labels: {app: orders, track: canary}
    spec:
      containers:
        - name: orders
          image: example.invalid/orders:fixture
          ports:
            - containerPort: 8080
```

## Concepts

All Service selector pairs must match a Pod. A declared container port does not start a listener. A Helm render is a candidate manifest, not a deployed observation.

## Tasks

Choose whether the Service should route to stable or canary. Propose a consistent values contract; compare baseline and proposed `helm template` output when using your own chart. Distinguish API defaults from actual runtime blockers in this deliberately limited fixture.

## Expected observations

No pod template matches `track: stable`. The image reference is deliberately unresolvable. Check API defaults before alleging that omitted replicas or restartPolicy fields are errors. Explain what rendering alone cannot establish.

## Verification

Write a selector truth table and distinguish schema validity, image availability and actual endpoint readiness. Optional cluster: use a real reviewed local image, then inspect EndpointSlices and an HTTP request.

## Troubleshooting

Do not change immutable Deployment selectors casually. Confirm labels on actual Pods, not only chart values.

## Cleanup

Default is offline; remove temporary renders. Optional cluster: remove only your lab namespace.
