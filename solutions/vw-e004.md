# Solution: Render Helm values before approving a change

`VW-E004` · Author guidance; independently unreviewed.

## Worked reasoning

`app=orders` matches, but `track=stable` does not match `track=canary`. Decide the rollout intent before changing either side; removing track would route to both tracks if both existed. The example image is deliberately unresolvable, so the rendered YAML cannot establish runtime readiness.

The default replicas value is one; Pod restartPolicy defaults to Always. These are not missing-required-field errors. Verify defaults instead of inventing a schema error. A local render verifies template expansion; server-side validation verifies API acceptance; EndpointSlices and requests verify different operational properties. All are separate records.
