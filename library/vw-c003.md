# An image tag is not a release identity

`VW-C003` · intermediate · 25 minutes · draft · free/local

## Question

Two nodes report `inventory:stable`, yet return different build IDs. How can both reports be true?

## Task

Explain mutable tags, content digests and platform-specific images. Propose the evidence needed to reproduce a release, including configuration and dependencies. State what pinning a digest does and does not guarantee.

## Verification

Your release record must identify source revision, image digest, target platform and config revision. Explain why reproducibility alone is not a security assessment.
