# Solution: Build a read-only incident evidence assistant

`VW-P002` · Solution and reasoning

## Reference design

Resolve the requested fixture path and require it to remain relative to the resolved fixture root before reading. A suffix check alone is insufficient. Return only allowlisted file contents with stable line IDs. Keyword retrieval should include a no-match result, not always return a passage.

## Adapter and evaluation

Use a mock callable with explicit responses and raised TimeoutError; validate JSON types and field sets before rendering. Check evidence IDs against the supplied set, then evaluate claims against each scenario's expected facts. A correctly shaped false assertion must fail groundedness. On error, render raw approved evidence with “no validated suggestion available.” Never evaluate an execution field by running it.

## Limits

This is an offline assistant architecture exercise. It does not establish real model performance, semantic retrieval quality or prompt-injection immunity. A genuine controlled agent extension would require bounded tool permissions, an action loop, approval gates, audit records and adversarial evaluation.
