# Engineering foundations

Start here if you are new to operating software or want to make your reasoning easier to verify. Foundations connect engineering tools to user outcomes, safe experiments and explainable decisions.

## Learning sequence

| Section | Prerequisites | What you will demonstrate | Availability |
| --- | --- | --- | --- |
| [Engineering outcomes and evidence](engineering-evidence/README.md) | None; reading tables and basic arithmetic | Define success, inspect evidence, compare alternatives and write a justified release handoff | Authored draft; offline fixture calculations checked |
| Safe local learning environments | Outcomes and evidence | Identify a disposable workspace, tool versions, action scope and safe cleanup | Planned section; existing [Day 2](../journey/days/day-02.md) and [Day 3](../journey/days/day-03.md) are starter activities |
| Changes, feedback and shared ownership | First two sections | Design a small change, actionable feedback and a clear handoff | Planned section; [VW-C001](../library/vw-c001.md) introduces shared responsibility |

The [100-day journey](../journey/README.md) provides a daily route. Sections give you deeper topic study without requiring the full sequence. The [section plan](../docs/section-plan.md) shows later learning areas and their prerequisites.
