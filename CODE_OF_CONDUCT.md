# Community code of conduct

Be respectful, curious and constructive. Welcome learners across regions, identities, abilities and levels of experience. Explain unfamiliar terms, critique work rather than people, and accept corrections with evidence.

Harassment, threats, discrimination, doxxing, sexualised conduct and repeated personal attacks are unacceptable. Do not publish personal or sensitive information without consent. Maintainers apply these expectations to repository issues, pull requests and discussions.

Report public conduct problems to the repository owner through a verified GitHub contact route. If a report contains private information, request a private channel without posting the details publicly. A dedicated private reporting address has not yet been established.

Maintainers may request edits, remove harmful content, close discussions or restrict participation. Responses should be proportionate to impact and repeated behavior. Where possible, explain the action privately and allow the person to provide context. Maintainers involved in a report should seek an uninvolved reviewer when available.
